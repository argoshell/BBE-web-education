# beer_web

Interactive web ports of Randall Beer's evolutionary agent simulations
(CTRNN, TSearch, LeggedAgent, ...). See [docs/PLAN.md](docs/PLAN.md).

The original C++ is not redistributed here; run `node scripts/fetch-beer-sources.mjs`
to download it from https://rdbeer.pages.iu.edu/ into `reference/`.
